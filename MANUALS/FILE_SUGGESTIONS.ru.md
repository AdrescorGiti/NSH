# Подсказки файлов

[English](FILE_SUGGESTIONS.md)

Скопируйте [пример file-suggestions](../examples/plugins/file-suggestions/) в каталог `plugins/` конфигурации NSH. Включите его командой `nsh plugin enable file-suggestions`.

Введите начало пути в конце строки. Плагин выбирает самый короткий подходящий суффикс, а при равной длине — лексически первый; для каталога добавляется `/`. Нажмите стрелку вправо, чтобы принять видимый суффикс. Enter выполняет фактически набранную строку без визуальной подсказки. Перемещение влево убирает подсказку.

Lua-код обрабатывает относительные и абсолютные пути, `~/`, Unicode, пробелы и введённые shell-кавычки. Слова, требующие раскрытия параметров, подстановки команд или шаблонов, он оставляет оболочке. Снимки каталогов считываются асинхронно с ограничениями. В очень больших каталогах часть записей и устаревшие снимки могут быть временно недоступны. Без этого плагина поиск подсказок не выполняется.

В NSH 0.2.1+ добавьте следующие параметры в установленный `plugin.toml`, чтобы настроить оформление подсказки. После сохранения выполните в NSH `nsh plugin reload file-suggestions`. Допустимые поля описаны в [API стилей](PLUGIN_API.ru.md#стили-редактора).

~~~toml
[options.ghost]
fg = "#8ADCF0"
italic = true
~~~
